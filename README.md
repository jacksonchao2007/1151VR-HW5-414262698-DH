製作流程和相關操作: 建構了寶可夢收服展示場景。場景整合了草地地形、樹木植被以及後方起伏山脈作為環境背景，並在場地左側配置訓練家模型，右側配置相對而立的寶可夢模型。透過腳本，系統實作了精靈球從訓練家位置由左至右以拋物線軌跡飛向寶可夢的動態效果；當精靈球抵達寶可夢所在座標時，系統會即時在目標位置生成收服粒子特效，同時隱藏被收服的寶可夢物件，並於短暫停留後清除精靈球以完成整套收服流程。
